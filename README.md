# Desafios SQL Parte 1- Beecrowd

Soluções dos desafios de SQL realizados na plataforma Beecrowd.

## Tecnologias

* PostgreSQL
* SQL

## Habilidades praticadas

* `SELECT`, `WHERE`, `JOIN` e `LEFT JOIN`
* `GROUP BY` e `ORDER BY`
* Funções `SUM`, `AVG`, `MAX`, `MIN`
* `COALESCE` e `ROUND`
* Subconsultas
* Funções de janela (`OVER`)

## Organização

* `Parte-1/solucoes/` → queries dos desafios
* `Parte-1/prints/` → prints dos desafios resolvidos com sucesso
